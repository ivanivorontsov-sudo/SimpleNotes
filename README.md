# SimpleNotes — Простая программа для заметок

Лёгкая десктопная программа для создания и хранения заметок на Windows (и других ОС).

## Возможности

- Создание, редактирование и удаление заметок
- Поиск по заголовку и содержимому
- Сохранение заметок в JSON-файл в папке пользователя (`~/.simplenotes/notes.json`)
- Экспорт / импорт отдельной заметки в текстовый файл
- Полная резервная копия всех заметок в JSON
- Экспорт всех заметок в ZIP с отдельными Markdown-файлами
- Импорт резервных копий SimpleNotes и ZIP-архивов с Markdown/TXT
- Горячие клавиши: `Ctrl+N`, `Ctrl+S`, `Ctrl+D` / `Delete`
- Простой интерфейс на Tkinter

## Резервные копии и перенос заметок

В меню **Файл** доступны три команды:

- **Экспортировать все (JSON)** — сохраняет все заметки вместе с идентификаторами и датами. Этот файл предназначен для полного восстановления в SimpleNotes.
- **Экспортировать все (Markdown ZIP)** — создаёт архив с отдельным Markdown-файлом для каждой заметки и файлом `notes.json` для точного восстановления. Markdown-файлы можно читать и использовать в других редакторах.
- **Импортировать резервную копию** — принимает JSON-резервную копию SimpleNotes или ZIP с Markdown/TXT-файлами в UTF-8. Для Markdown заголовок первой строки `# Заголовок` становится названием заметки; для TXT названием становится первая строка.

Импорт работает безопасно: он **добавляет** заметки к существующим, а не заменяет их. Полностью совпадающие записи пропускаются. Если идентификатор уже занят другой заметкой, импортированная версия получает новый идентификатор — обе версии сохраняются. Перед записью приложение показывает сводку и просит подтверждение.

Ограничения импорта: до 20 МБ на архив/резервную копию, до 2 МБ на одну заметку и до 50 000 заметок. Архивы проверяются на небезопасные пути; файлы не распаковываются в системные каталоги.

Данные остаются в локальной папке пользователя. Сетевые запросы и телеметрия приложением не используются; резервная копия создаётся только после выбора места сохранения.

## Скачать готовую версию (Windows)

Перейдите в раздел **[Releases](https://github.com/ivanivorontsov-sudo/SimpleNotes/releases)** и скачайте:

- `SimpleNotes.exe` — портативная версия (просто запустить)
- `SimpleNotes-Setup.exe` — установщик (рекомендуется)

> Релизы автоматически собираются через GitHub Actions при создании тега.

## Запуск из исходников

Требуется Python 3.8+.

```bash
git clone https://github.com/ivanivorontsov-sudo/SimpleNotes.git
cd SimpleNotes
python main.py
```

Никаких дополнительных зависимостей для приложения не нужно — используется стандартная библиотека Python + Tkinter.

## Проверка тестов

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют формат резервной копии, экспорт Markdown ZIP, импорт Markdown/TXT, конфликты идентификаторов и защиту от небезопасных путей в ZIP.

## Сборка EXE самостоятельно (Windows)

1. Установите Python 3.8+ и добавьте в PATH.
2. Установите PyInstaller:

```bash
pip install pyinstaller
```

3. Соберите:

```bash
pyinstaller --noconfirm --onefile --windowed --name SimpleNotes main.py
```

Готовый файл будет в папке `dist/SimpleNotes.exe`.

### Создание установщика (Inno Setup)

1. Установите [Inno Setup](https://jrsoftware.org/isinfo.php).
2. Откройте файл `installer.iss` и скомпилируйте его.
3. Установщик появится в папке `Output`.
